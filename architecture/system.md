# System architecture

See [asteria_ai_platform_build_plan.md](./asteria_ai_platform_build_plan.md) for the full target architecture.

Sprint 0 delivers the foundation only:

- React + Vite UI
- FastAPI API gateway
- PostgreSQL
- Redis
- Ollama (local LLM runtime)
- Docker Compose

Agents, RAG, MCP, and the AI harness are introduced in later sprints.
